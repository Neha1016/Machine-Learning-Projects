# Crop Advisor

A basic Machine Learning project that recommends suitable crops based on agricultural and environmental conditions.

## Project Overview

Crop selection is an important decision in agriculture. This project uses Machine Learning to recommend a suitable crop based on input features such as soil and environmental conditions.

## Dataset

The dataset contains agricultural information used to train the Machine Learning models for crop recommendation.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning

The project includes data preprocessing, exploratory data analysis, feature preparation, model training, and model evaluation.
